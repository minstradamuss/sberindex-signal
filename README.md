# SIGNAL · СберИндекс

Прогноз средних безналичных расходов муниципалитетов на **1, 3, 6, 12 месяцев**, сравнение с Prophet и Chronos, онлайн-мониторинг изменений и предупреждения о риске следующего месяца.

Проект для направления «Прогнозирование» онлайн-конкурса СберИндекса 2026. Числа получены реальным запуском; результаты синтетических экспериментов явно отделены от результатов на настоящих расходах.

* [Сохранённые метрики](results/full/metrics.csv), [парное сравнение с Prophet](results/full/metrics_paired_prophet.csv)

Проект реализует комбинацию частичного объединения сезонности между МО, глобальных поправок CatBoost/LightGBM и Chronos-Bolt Small. Ансамбль выбирает веса только по уже завершившимся прогнозам. Два варианта Prophet проверяются на заранее выбранных 512 МО; все сравнения с ними парные. Остальные модели проверяются по всей доступной панели из 2 190 МО.

Основной алгоритм - `signal_ensemble`. Дополнительный вариант `signal_adaptive` опубликован как исследовательская абляция: он не улучшил основной ансамбль на горизонтах 1,3,6. Отдельного нового теста после итогового выбора основного варианта нет; сравнение всех фиксированных методов открыто.

В данных всего 24 месяца. Для h=12 есть одна полноценная точка старта. Превосходство на этом эпизоде не является доказательством универсального качества. Официальные параметры baseline организатора неизвестны; настройки двух наших вариантов Prophet открыты.

## Измеренный результат

MAE по «Все категории» в рублях, на общих наблюдениях фиксированной выборки Prophet:

| Горизонт | SIGNAL | Prophet default | Снижение MAE |
|---|---:|---:|---:|
| 1 месяц | 801.71 | 2251.81 | 64.4% |
| 3 месяца | 883.05 | 2431.17 | 63.7% |
| 6 месяцев | 1101.24 | 2358.54 | 53.3% |
| 12 месяцев | 2511.13 | 3054.26 | 17.8% |

На всей доступной панели MAE основного ансамбля: **780.24 / 862.45 / 1084.90 / 2421.06 ₽** соответственно. Эти числа нельзя напрямую делить на MAE Prophet, рассчитанную на другой выборке; для сравнения служит таблица выше. Полные числа, R², второй Prophet, категории и ограничения находятся в [RESULTS.md](docs/RESULTS.md).

В полусинтетическом тесте выбран BOCPD: средний recall 0.620, precision 0.417, 3.17 тревоги на 100 контрольных ряд-месяцев. Это не оценка точности предсказания реальных экономических кризисов.

## Установка

Проверено на Python 3.12, CPU. GPU не требуется. Понадобится доступ к PyPI и Hugging Face для первого запуска с фундаментальной моделью. Веса Chronos скачиваются отдельно и не включены в GitHub-репозиторий.

Основные 12 точек backtest заняли около 44 минут при настройке на 8 вычислительных потоков, без учёта установки и загрузки весов. Для полного расчёта удобно иметь 16 GB RAM. Просмотр готовых таблиц и PDF не требует обучения.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux / macOS:
# source .venv/bin/activate
python -m pip install -r requirements.lock.txt
python -m pip install -e . --no-deps
```

Если PowerShell не разрешает активацию, используйте `.venv\Scripts\python.exe` вместо `python`: менять системные политики не нужно.

## Готовые данные

`data/raw/consumption.parquet` и исходный PDF с описанием уже включены по CC BY-SA 4.0. Начать можно без обращения к сайту Сбера. SHA-256 исходного архива и parquet приведены в `data/manifest.json`.

Для повторного получения из официального источника:

```bash
python scripts/download_data.py
# Если архив уже скачан:
python scripts/download_data.py --archive /path/to/hackathonlicence.zip
```

Скачивание не исполняет содержимое архива, извлекаются только заранее определённые файлы. Несовпадение контрольной суммы требует проверки новой версии данных.

## Воспроизведение

Проверка целостности распакованного архива и пересчёт опубликованных метрик из сохранённых прогнозов:

```bash
python scripts/verify_checksums.py
python scripts/verify_results.py
```

Контрольные суммы относятся к содержимому поставки. После собственного повторного расчёта результаты могут измениться, и проверка исходных сумм закономерно сообщит об изменениях.

Быстрый тест всего вычислительного пути без скачивания весов:

```bash
python -m pytest -q
signal-run backtest --config configs/smoke.yaml --limit 24
```

Основной расчёт (прогнозы, детектирование, отчёт и презентация):

```bash
signal-run all --config configs/full.yaml
```

В ZIP уже есть завершённые результаты. Команда продолжает расчёт с существующих контрольных точек. Для независимого запуска с нуля используйте конфигурацию `configs/reproduce.yaml`, у которой другая папка результатов:

```bash
signal-run all --config configs/reproduce.yaml
```

Полное сравнение Prophet по всем МО доступно отдельно и требует больше времени:

```bash
signal-run all --config configs/prophet_all.yaml
```

Можно запускать этапы отдельно:

```bash
signal-run backtest --config configs/full.yaml
signal-run refine --config configs/full.yaml
signal-run detect --config configs/full.yaml
signal-run report --config configs/full.yaml
signal-run forecast --config configs/full.yaml
```

Последняя команда формирует **исторические** прогнозы из декабря 2024 на 2025. Данные заканчиваются в 2024, поэтому это не актуальный прогноз на дату конкурса в 2026. В `future_forecasts.parquet` факты отсутствуют и такие строки не включаются в метрики качества.

`results/full/operational_snapshot.csv` объединяет для каждого МО прогнозы четырёх горизонтов, последнее наблюдение, сигнал выбранного детектора и вероятность крупного относительного изменения следующего месяца. Вероятность рассчитана только для полных рядов; пустое значение не означает отсутствие риска. Это готовая таблица для аналитика, с честно указанной исторической датой.

## Структура

```text
configs/                  сохранённые конфигурации экспериментов
data/raw/                 исходная таблица СберИндекса и описание лицензии
data/external/news.json    17 проверенных публикаций Банка России
data/manifest.json        версии и контрольные суммы данных
src/signalcast/           загрузка, модели, ансамбль, backtest, детекторы, отчёт
scripts/                  загрузка данных, проверка артефактов
tests/                    временная причинность, метрики, новости, детекторы
results/full/             прогнозы, метрики, веса, сигналы, настройки и время
docs/                     методология, результаты, презентация, инструкции
.github/workflows/        автоматическая проверка тестов
notebooks/                просмотр результатов и выбор своего примера МО
```

`predictions_h*.parquet` содержат факты и прогнозы на обязательных горизонтах, отдельным файлом на горизонт. `origin_*.parquet` - более подробные контрольные точки со всеми горизонтами. `metrics_paired_prophet.csv` использует только общие наблюдения двух baseline и сравниваемых моделей. `detection_metrics.csv` относится исключительно к внесённым событиям. `early_warning_metrics.csv` относится к статистическим меткам следующего месяца. `real_alerts.csv` не содержит подтверждённых причин шоков.

## GitHub

Распакуйте ZIP и загрузите **содержимое папки `sberindex-signal`** в корень нового репозитория, включая папки `docs`, `results`, `data`, `src` и скрытую `.github`. Не загружайте `.venv` или `.cache`. Код, данные и результаты доступны непосредственно из репозитория; PDF открывается в интерфейсе GitHub.

Для полной поставки используйте Git по инструкции ниже: часть подробных файлов прогнозов превышает браузерный лимит 25 MiB, но каждый файл укладывается в ограничение обычного Git-репозитория 100 MiB. [Ограничения GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

Перед отправкой конкурсной формы впишите своё название команды и реальных участников. Публичный URL репозитория появится только после вашей загрузки. Проект не отправлен организаторам автоматически.

Подробно: [PUBLISHING.md](docs/PUBLISHING.md).
