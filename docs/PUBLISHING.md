# Как загрузить на GitHub и подать проект

1. Распакуйте архив. Корень репозитория должен содержать README.md, pyproject.toml, configs, src, data, results и docs.
2. Создайте репозиторий с доступом на просмотр. Загрузите файлы через Git, используя команды ниже: часть файлов с подробными прогнозами превышает браузерный лимит 25 MiB. Все отдельные файлы меньше 100 MiB, поэтому Git LFS для этой поставки не требуется. [Официальные ограничения](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).
3. Убедитесь, что открываются README, docs/PRESENTATION.pdf и docs/METHODOLOGY.md. Результаты уже лежат в архиве: посетителю не нужно обучать модели для просмотра чисел.
4. Укажите настоящее название команды и участников в README. Авторские утверждения и содержание работы необходимо прочитать перед подачей.
5. Проверьте зелёный результат GitHub Actions. Он проверяет код и свойства временной причинности, но не повторяет длительное обучение.
6. В конкурсной форме выберите «Прогнозирование», вставьте URL репозитория, заполните свои данные и отправьте до срока из актуальных условий. Согласия пользователь даёт самостоятельно.

Пример команд из распакованной папки после создания удалённого репозитория:

```bash
git init
git add .
git commit -m "Add reproducible SberIndex forecasting research"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git
git push -u origin main
```

Замените YOUR_ACCOUNT и YOUR_REPOSITORY своими значениями. В проекте нет токенов или паролей. Веса Chronos, окружение Python и кэш должны оставаться вне Git.

Короткое описание для формы (проверьте и отредактируйте от имени команды):

> Исследуем, насколько объединение информации между муниципалитетами помогает прогнозировать короткие ряды потребительских расходов. Решение сочетает сезонную панельную модель, CatBoost/LightGBM и Chronos, сравнивается с двумя вариантами Prophet на горизонтах 1, 3, 6 и 12 месяцев. Отдельно проверяются причинные детекторы изменений и риск крупного отклонения следующего месяца. Новости Банка России присоединяются по дате публикации. Публикуем исходные прогнозы, метрики, конфигурации и ограничения, включая короткую историю и отсутствие разметки истинных экономических шоков.
