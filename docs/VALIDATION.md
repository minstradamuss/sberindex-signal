# Что проверено перед упаковкой

Дата: 01.10.2026. Среда: Python 3.12.14, Windows 11, CPU; версии библиотек закреплены в requirements.lock.txt.

- 15 автоматических тестов прошли. Они проверяют численные метрики, запрет доступа к будущему при заполнении данных, новостях и выборе весов, правильную привязку горизонта, пропуски фактов, причинность детекторов и задержку тревоги.
- Полный backtest завершён для всех 12 точек старта. Chronos-Bolt Small действительно загружен и запущен; версия весов записана в run_manifest.json.
- Из 5 599 512 сохранённых прогнозов обязательных горизонтов заново рассчитаны 644 строки метрик. MAE, R², WAPE и размеры выборок совпали с опубликованными таблицами. Парное сравнение с Prophet пересчитано отдельно.
- Проверены уникальность ключей прогнозов, конечность и положительность предсказаний, временное расстояние до цели, суммы и неотрицательность весов, раздельные группы детекторов и SHA-256 исходных данных и новостей.
- В журнале Prophet 104 пропуска в backtest и ещё 5 при историческом прогнозе из декабря 2024 по правилу «меньше шести прошлых наблюдений». Это исключение непригодных рядов, а не замена неудачного Prophet другой моделью. Непредвиденных ошибок модели не зарегистрировано.
- PDF содержит 12 страниц. Все страницы отрисованы и просмотрены; исправлены пересечения текстов и таблицы. Notebook валиден для nbformat 4; все его кодовые ячейки выполнены на поставленных результатах.
- Исторический прогноз из декабря 2024 проверен отдельно: фактов будущего в файле нет, предсказания положительны, горизонты и ключи корректны. Сводка для аналитика совпадает с прогнозами исходного ансамбля; непустые вероятности риска лежат в [0,1].

Эти проверки подтверждают вычислительную согласованность артефактов. Они не создают недостающие независимые годы наблюдений и не доказывают экономическую причинность. Итоговый выбор исходного ансамбля выполнен после сравнения двух исследовательских вариантов; нового отложенного теста после этого выбора нет.

Команды проверки:

```bash
python -m pytest -q
python scripts/verify_checksums.py
python scripts/verify_results.py
```

ARTIFACTS.sha256 фиксирует поставленные файлы, включая исходный код и численные результаты. После собственных изменений несовпадение контрольной суммы ожидаемо.
