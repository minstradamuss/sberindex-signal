# Проверка требований конкурса

Основание: текст условий, предоставленный пользователем 01.10.2026. Официальная форма и пользовательские согласия в проект не копируются.

| Критерий | Вес | Реализация / проверяемый артефакт |
|---|---:|---|
| Простое объяснение методологии | 10% | METHODOLOGY.md, схема в PDF |
| Сравнение с Prophet, горизонты 1/3/6/12 | 20% | Два Prophet, 512 заранее выбранных МО, одинаковые пары; metrics_paired_prophet.csv; полный расчёт остальных моделей |
| Сравнение и выбор детекторов | 20% | Четыре причинных метода; выбор на калибровочных МО, отдельная проверка; detector_selection_calibration.csv, detection_metrics.csv |
| Фундаментальные модели | 15% | Реальный запуск Chronos-Bolt Small, два режима, commit весов закреплён |
| Новости и согласование времени | 15% | 17 официальных публикаций, as-of признаки, абляция с/без новостей, ранние календарные предупреждения |
| MAE обязательна, R² дополнительно | 10% | Обе метрики в рублёвом масштабе, дополнительно RMSE/WAPE |
| Интерпретация и воспроизводимость | 10% | Реальные id, отчёт, PDF, исходные прогнозы, версии, seed, тесты |

## Комплект сдачи

- Исходный код и инструкция запуска: README, src, scripts.
- Настройки гиперпараметров: configs/*.yaml.
- Методологический отчёт на русском: docs/METHODOLOGY.md и docs/RESULTS.md.
- Презентация результатов в PDF: docs/PRESENTATION.pdf.
- Минимум один набор СберИндекса: включён consumption.parquet с атрибуцией и лицензией.
- GitHub: архив подготовлен для загрузки; пользователь публикует репозиторий и отправляет его URL в форму.

Ограничения, влияющие на оценку: нет настоящей разметки экономических шоков; годовой прогноз проверен из одной точки; узкий федеральный новостной корпус; точные параметры baseline организатора не опубликованы в предоставленном тексте; справочник названий МО отсутствует. Эти ограничения не скрыты за красивыми метриками.
